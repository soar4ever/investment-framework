# 投资框架仪表盘

[打开仪表盘](https://soar4ever.github.io/investment-framework/)

中文单文件投资研究工作台，含第一性原理、仓位结构、执行规则、风险计算、五个交易主题、决策树、宏观状态机及药物研发流程。

个人笔记、仓位输入和研究主题只保存在访问者自己的浏览器中，不发送到 GitHub。跨设备或从本地版迁移时，请使用 JSON 导出与导入；这不是账户或交易执行系统。

页面与默认框架公开。宏观数据由已有的本机维护任务每日北京时间 08:30 同步；维护电脑与 Codex 需要保持运行。GitHub Pages 本身只提供静态网页，不能采集金融数据。数据日期、来源与时效以页面显示为准。

自动广度是 SPY 当前持股固定样本的 200 日均线代理。缺少历史时仅显示保守范围，不替代为部分样本的精确百分比。

网页源文件为 index.html；.nojekyll 保持静态发布。后续数据同步只修改 macroAutoSnapshot 的 JSON 区块，保留其他网页内容。
